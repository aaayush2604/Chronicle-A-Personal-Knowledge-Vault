# Chronicle-A-Personal-Knowledge-Vault

This project started as an attempt by me to learn GO

Just building a personal project allowing me to note down my thoughts into different categories and being able to use those thoughts/learnings/questions at the right time. This project currently is just a simple append-only log that lets you enter notes and allows you to pull those thoughts based on the words you might think are used in those entries. Currently working on trying to add a somewhat working query language to this, allowing for better search and better usability. If trying to see all the features that this currently has, use help in the terminal. The path to logFile is displayed on the terminal when the project starts. If you want to add a particular path for the logFile, apart from the default, just add CHRONICLE_LOG_FILE_PATH to an env file
